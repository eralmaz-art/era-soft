# ERA SOFT Design System

Status: **Draft for product review**  
Phase: **3 — Design System**  
Scope: product foundations and UX contracts; no production implementation

This pack is the proposed constitution for the ERA SOFT user experience. It
turns the brand direction—graphite, Deep Green, calm light surfaces, strict
typography, generous whitespace, and restrained detail—into rules that can be
reviewed before code is written.

## Approval boundary

Approval of the architecture phase does not approve these visual decisions.
Before implementation starts, the product owner must explicitly approve:

- the palette and typography direction;
- component density and interaction rules;
- the Owner Dashboard information hierarchy;
- the construction-object information hierarchy;
- the screen review gate and its approvers;
- all P0 questions in `07-open-questions.md`.

Until then, the existing ERPNext visual baseline remains the working interface.
This pack adds no DocTypes, workflows, reports, client scripts, or production CSS.
