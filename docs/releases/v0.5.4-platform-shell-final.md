# ERA SOFT v0.5.4 — Platform Shell Final

Status: Stable release candidate

## Release summary

ERA SOFT Platform Shell is ready to be frozen as the stable product entry point. This release completes the final interface review before product development focuses on ERA Construction.

## Included

- ERA GROUP portfolio scale is visible in the command-center hero.
- ERA Construction exposes version, recent product changes, last update time, and module readiness.
- ERA Concrete and SRIS Bishkek communicate their Roadmap position and release sequence.
- Official application logos have final spacing, alignment, and responsive sizing.
- Application cards retain restrained motion, premium whitespace, and reduced-motion support.
- Platform Shell remains upgrade-safe and contains no ERPNext core changes.

## Verification

- Repository tests: 12 passed.
- Frappe integration tests: 8 passed.
- Asset build and site migration completed.
- Desktop, tablet, mobile, light, and dark compatibility reviewed.
- Official logos load without distortion or broken assets.

## Product boundary

After this release, Platform Shell is considered frozen. Future shell changes require a concrete user problem, accessibility defect, security issue, or confirmed cross-application requirement. Normal development moves to working ERA Construction capabilities.

## Version note

The repository already contains `v0.5.1-platform-shell`, so publishing the current commit as `v0.4-platform-shell` would move the release history backwards and conflict with application version `0.5.4`. The consistent release tag is `v0.5.4-platform-shell-final`.
