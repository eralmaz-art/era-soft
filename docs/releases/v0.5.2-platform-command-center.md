# ERA SOFT v0.5.2 — Platform Command Center

Status: Development candidate

## User value

The ERA SOFT home page now works as a company command center rather than a static application catalogue.

- Personal greeting, current date and time, and active company context are visible immediately.
- Search, recent actions, and notifications are available as direct actions.
- The Executive Dashboard is the first standalone management entry point.
- ERA Construction communicates its active status, current product version, last update, and module readiness.
- ERA Concrete explains that its start follows the Construction MVP.
- The platform mission is visible without changing any ERPNext core files.

## Scope

This release changes only the upgrade-safe ERA SOFT presentation layer. It does not add DocTypes, workflows, accounting rules, or other business functionality. The existing Construction MVP capability remains unchanged.

## Verification

- Build ERA SOFT assets.
- Migrate and clear the local `era.localhost` cache.
- Open `/desk/era-soft` and confirm the command center, Executive Dashboard entry, application metadata, and responsive layout.
- Confirm that search, recent actions, notifications, and the Construction link use existing Frappe controls and routes.
- Run repository and Frappe application tests.
