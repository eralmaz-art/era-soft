# ERA SOFT v0.5.3 — Official application branding

Status: Development candidate

## User value

The Platform Shell now communicates a recognizable product ecosystem through official application identities.

- ERA Construction uses the official ERA corporate mark.
- ERA Concrete uses the official Latin ERA Concrete mark.
- ERA Education is presented to users as SRIS Bishkek and uses the official SRIS shield.
- Application cards have consistent logo holders, spacing, hierarchy, release-stage information, and restrained motion.
- Official raster artwork remains undistorted and uses white holders for reliable light and dark theme presentation.

## Scope

This is a visual identity release only. It does not introduce business logic, DocTypes, workflows, or ERPNext core changes.
